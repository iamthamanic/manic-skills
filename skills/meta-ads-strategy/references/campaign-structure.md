# Meta campaign structure

## Prospecting

Default to a small number of broad or strategically distinct ad sets. Split only for material differences such as geography, economics, legal constraints, language, offer, or creative strategy.

Do not create separate ad sets for every interest unless the test question requires it and budget supports it.

## Retargeting

Use `retargeting-funnel` for staged design.

Meta implementation checks:

- define Custom Audiences from actual available sources,
- exclude converted users when acquisition is the objective,
- exclude hotter stages from warmer stages when stages are separated,
- verify whether Advantage+ audience expansion can go beyond selected audience inputs,
- use manual/original audience controls when the account exposes them and strict audience control is required,
- avoid tiny ad sets that cannot spend efficiently.

## Placements

Advantage+ placements are a reasonable default when the creative works across placements. Use manual exclusions only for a documented performance, brand-safety, creative-fit, or operational reason.

## Budget

Use the smallest number of campaigns/ad sets that can answer the test question. Fund each active ad set enough to generate interpretable outcomes; otherwise consolidate.

For small retargeting pools, budget should follow audience capacity. Rising frequency with stagnant reach and conversions is a signal that the pool or creative is exhausted.

## Current Meta behavior

Meta's 2026 developer guidance describes both Advantage+ and manual campaign/audience paths in some products and warns that overly narrow audiences may increase costs and creative fatigue. Exact Ads Manager options vary by account and rollout.
