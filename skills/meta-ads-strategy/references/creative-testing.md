# Meta creative testing

## Creative matrix

Vary concepts, not just wording.

Useful dimensions:

- problem/pain,
- desired outcome,
- demonstration,
- proof/testimonial,
- objection handling,
- comparison/differentiation,
- process transparency,
- urgency when genuine.

For video, test distinct opening concepts rather than five cosmetic edits to one hook.

## Retargeting creative

Do not simply repeat prospecting creative. Use deeper proof, process clarity, FAQs, trust, or friction removal based on the user's stage.

## Test discipline

For each test define:

- hypothesis,
- variable being changed,
- primary metric,
- minimum evaluation window or evidence threshold,
- kill criterion,
- scale criterion.

Avoid changing audience, budget, placement, and creative simultaneously when the goal is to learn which variable caused the result.
