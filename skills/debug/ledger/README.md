# Global debug ledger (optional)

Append solved bugs here for cross-project search. **No secrets, tokens, or PII.**

Filename: `YYYY-MM-<topic>.md` or one `patterns.md`.

The `@debug` skill searches this folder in Step 6 (knowledge-sources.md).

Projects may also keep **`.qa/debug-log.md`** in the repo for team-visible history.
